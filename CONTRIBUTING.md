# Contributing to ic-app

Thanks for your interest in the project.

## Bug reports & feature requests

Bug reports and feature requests are welcome — please [open an issue](../../issues).
Clear reproduction steps and version details help a lot.

## Pull requests

We are **not currently accepting pull requests**. This may change as the project
matures; for now, filing an issue is the best way to contribute.

## Security issues

Please do **not** report security vulnerabilities through public issues. See
[SECURITY.md](SECURITY.md) for how to report them privately.
